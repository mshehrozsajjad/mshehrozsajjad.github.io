# Logos

- `shehroz-wordmark.svg`: the playhead mark in `signal` (#2D2BE0) and the name in `ink` (#111113), Instrument Sans 600 outlined. Use on `paper`.
- `shehroz-wordmark-ondark.svg`: the mark in `stage-signal` (#8E8CFF) and the name in `on-stage` (#F3F3EF). Use on `stage` and in the dark theme.
- `shehroz-mark.svg`: the playhead alone in `signal`, for favicons, avatars and small sizes.

Keep clear space equal to the mark's width on every side. The SVGs are fixed-colour files, so pick the variant for the ground rather than recolouring.
