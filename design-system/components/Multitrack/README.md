# Multitrack

The signature component: his body of work as an editing timeline. Rows are the five lanes (Design, Code, Hardware, Film, Sound), columns are projects in experiment order, and a clip sits on every lane he worked in for that project. The `signal` playhead and `signal` clips mark the current project. Everything else is `ink` on `lane`.

Use it once on the homepage, as the proof of range, and as the archive's optional view. Hovering or focusing a column moves the playhead there and swaps the featured footage. On phones, turn it 90°: projects run down the page and the lanes become five narrow columns.

The consumer provides the project list in experiment order, each project's lanes, and the index of the active one. The lanes must be true. Don't add a lane for a single project, and don't fill a lane he didn't work in. A plain list of the same projects must always be one click away. The lanes in this preview are illustrative and need Shehroz's confirmation.
