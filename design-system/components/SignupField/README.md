# SignupField

The newsletter signup: one field and one primary button in a `radius-pill` frame, with a one-line promise under it in `sz-note`. It appears once on every page and is the site's main conversion.

The consumer provides the form handler (double opt-in, since he's in Germany), a visually hidden label and the promise line. Keep it to an email field only. No name field, no checkboxes, no pop-ups. After submitting, replace the note with "Check your inbox to confirm." in the same place.
